# Tech Cart

Tech Cart is a small Streamlit shopping app for browsing technology products.

## Requirements

- Python 3.9 or newer
- Streamlit

## Setup

Create and activate a virtual environment, then install Streamlit:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install streamlit
```

## Run

From the project directory, run:

```powershell
streamlit run app.py
```

Streamlit will open the app in your browser. If it does not, visit the local URL shown in the terminal.
